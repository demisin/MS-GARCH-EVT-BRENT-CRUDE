# MS-GARCH-EVT-BRENT-CRUDE
volatility models for WTI and Brent crude oil (2010–2025) in R. It uses rugarch, fGarch, and MSGARCH to run GARCH, EGARCH, GJR-GARCH, FIGARCH, FIAPARCH, and MS-GARCH under Gaussian and Student-t distributions. Extreme Value Theory (EVT) for VaR and ES, with Kupiec, Christoffersen, McNeil &amp; Frey, and Diebold-Mariano tests.
